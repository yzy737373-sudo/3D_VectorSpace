# 空间几何三题动画集

可交互的空间几何教学页面，包含三道题的题目、三维动画、滑块和五步讲解。

| 题目 | 内容 | 答案 |
| --- | --- | --- |
| 菱形折叠与外接球 | 二面角、垂直截面、球心定位与半径 | 52π/3 |
| 向量合并与体积 | 底面重心、向量相消、中点与同底体积比 | 2 |
| 带权向量与体积 | 竖直分量、高度平衡方程与体积比 | 8 |

## 使用

直接用浏览器打开根目录的 `index.html`。支持题目切换、自动演示、空间图形旋转和分步操作，切换题目时保留当前操作状态。

## 部署

这是单文件静态页面，所有样式、动画脚本和题目内容都已内嵌，无需安装依赖或执行构建命令。

- 入口文件：`index.html`
- 静态发布目录：仓库根目录
- 可用于 GitHub Pages 或其他静态网站托管服务
- `.nojekyll` 用于让 GitHub Pages 直接提供静态文件

页面也可以离线使用。
